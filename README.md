# Rubeho Community Engagement

Dashboard and Word reports for Rubeho's EarthRanger **Stakeholder meeting** events (`community_meeting`).
Same outputs as the Olokeri community engagement workflow
([eden-community_engagement](https://github.com/wildlife-dynamics/eden-community_engagement)):
total meetings, total participants, median participants per meeting, participants box plot,
gender and age splits, topics by forest cluster, and a choropleth of meetings per village.

## Groupers

| Grouper | Source |
|---|---|
| Period | quarter, semester, year or month (`temporal_index`) |
| Meeting type | `meeting_type` (multi-select; combinations become one label, e.g. "Co-creation, Negotiation") |
| Primary stakeholder | `primary_stakeholder_level_one` (National / Region / District / Village / Other) |
| Forest cluster | `meeting_location_level_one` |
| Village | village picked in the form, matched to the bundled village boundaries; falls back to the polygon the GPS point is in, else "Unmatched" |

Empty values group as "Unspecified".

The village boundaries (40 polygons) ship inside `ecoscope-workflows-ext-eden` (`load_rubeho_villages`).

## Development

- `spec.yaml`, `param.yaml`, `layout.json`, `test-cases.yaml`: workflow source. Recompile after any change:
  `pixi run compile-etd` (fresh) or `pixi run recompile-etd`.
- `mock-io/`: synthetic test events, generated by `.scripts/make_mock_io.py` (choice lists are real; all
  other values are made up).
- `.scripts/`: data-model exploration and a standalone dashboard preview used to design this workflow.
